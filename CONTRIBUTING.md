# Contributing

Thanks for helping improve Lulu.

## Bug reports and ideas

Open an issue with a short description, your operating system, and the Codex version or build where you observed the behavior. Screenshots or short recordings are especially helpful for visual issues.

## Pull requests

1. Fork the repository and create a focused branch.
2. Keep `pet.json` and `spritesheet.webp` together.
3. Preserve the Codex Pet v2 atlas contract: 8 columns × 11 rows, 192 × 208 px cells, and a final size of 1536 × 2288 px.
4. Preserve transparent unused cells and avoid introducing color data beneath fully transparent pixels.
5. Describe the visual or installation change in the pull request and include a preview when relevant.

Small, focused changes are easiest to review.
